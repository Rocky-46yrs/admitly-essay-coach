# PS 与 SOP：以实际题目为准

文书名称不能替代官方题目。同一学校可同时要求学术目的陈述和个人背景陈述；分别作答，避免整段重复。先拆题为要求清单，给每项分配段号；字数、字符、页数、字体、是否分题提交均原样记录。

## 常见重心，不是国家硬规则

| 材料 | 常见重心 | 容易误用 |
|---|---|---|
| SOP / academic statement | 学术准备、关注问题、学习计划、项目适配、未来方向 | 写成简历串联，或强行套博士导师研究计划 |
| PS / personal statement | 题目指定的个人背景、选择、成长及其意义；也可能要求学术内容 | 编苦难、强设人生转折，忽略课程准备 |
| 美国授课/职业型硕士 | 按项目要求解释准备与学习/职业路径；个人背景题可能独立 | 默认所有美国项目都需要科研导师 |
| 英国授课型硕士 | 按项目要求解释学科兴趣、现有准备、课程学习需求 | 默认“英国只看学术”、套固定500词限制 |

## 工作方法

建立“题目要求—证据F编号—段号—缺口”表。选少数能证明准备度的经历，写清任务、本人行动、可证结果和本人确认的理解；不要求每段机械包含所有要素。选择学习目标时从已有能力到具体缺口，再解释项目能提供的学习机会。目标还在探索可如实表达，不强迫编职业职称。

可用结构是：当前关注的问题 → 关键准备及认识 → 需要进一步学习的内容 → 经过核实的项目联系 → 下一阶段方向。个人背景题则围绕题目需要的经历与意义组织。顺序、段数随题目和材料变化，模板只作容器。

## 跨专业与弱经历

跨专业说明可迁移技能、已做准备及仍需补足内容。没有实习不扣“缺实习”分，课程项目、自主学习与工作任务都可提供证据。低分或空档只有在题目需要或用户愿意解释时处理；描述事实与后续行动，不诊断健康、不强迫透露创伤。

## 篇幅

以官方单位为准。英文工作计数可用空白分隔词数，明确连字符词、数字、标题的处理方式；字符计数说明是否含空格。没有可靠计数工具只报估计，不宣称精确达标。门户计数优先。超长优先删重复职责、套话与偏离题目的背景，再精简句子；不能为了达标删掉必要题目答案。未知上限时不自行设为学校要求。
