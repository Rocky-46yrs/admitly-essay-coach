# 申请场景路由

只收集会改变当前决策的信息，不一次问满表。默认顺序：有稿先看；明确题目优先；未知项目做通用编辑。

## 路由卡

学位（本科/授课硕士/研究硕士/博士/未知）、专业及转专业背景、国家、学校项目/校区、入学年度、文书类型、官方题目与限制、阶段（无稿/素材/策略/初稿/定校/终审）、规则核验状态。不能仅凭MSc/MA名称判断授课还是研究型。

| 情形 | 读取与处理 |
|---|---|
| 本科 Common App Essay、PS、Supplemental Essay | [本科模块](undergraduate.md)，区分主文书与单校补充题 |
| 授课硕士 PS/SOP | [PS/SOP指南](ps-sop-guide.md)，学习准备和需求 |
| 研究型硕士或博士 SOP/PS/Research Statement | [研究模块](research-applications.md)，准备、问题与可行性 |
| Research Proposal 与 Research Statement 名称不明 | 先查题目；不能把过去研究总结擅改为未来研究计划 |
| 独立个人背景题/短答题 | 实际题目决定内容，不机械加职业规划/Why school |
| 奖学金、MBA特定问答、专业资格申请等未设专门模块 | 明示只有通用编辑能力，先取得官方题目，不宣称专业全覆盖 |
| 推荐信代写、录取概率、检测规避 | 不进入文书生成；说明边界并提供相关可行替代 |

## 国家接入边界

这些是核验入口，不是预置各国招生规则。美国/英国有本科与研究生通用文类指导；加拿大/澳大利亚有按项目核验的接入路径；其他国家使用同一最小信息契约，均不代表全面学校覆盖。

| 国家/系统 | 本轮必须核对的差异 | 未核实时 |
|---|---|---|
| 美国 | 是否采用Common App、主文书或独立补充题、各自年度题目/限制 | 不默认所有学校使用同一系统、题目或长度 |
| 英国 | 本科是否经UCAS及当前年度回答格式；研究生按项目要求 | 不沿用旧年度单篇格式，不把UCAS本科格式推广到硕士 |
| 加拿大 | 学校/院系/项目的学位类型、个人材料要求、研究陈述或导师安排 | 不默认某省/全国共用PS或必须套磁 |
| 澳大利亚 | 项目具体申请文书、研究学位申请/提案要求、导师与资金条件 | 不将签证说明与招生文书混为一谈 |
| 其他国家 | 官方申请语言、学位模式、当地文类名称与实际题目 | 标记“通用指导，国家/项目要求待核实” |

## 扩展接口（文档约定，无代码）

接入新场景只需补充：国家/系统、学位、年度、文类、官方题目、长度单位、AI政策、来源与核验状态。将题目映射到已有模块；确有不同专业判断时新增一个小reference并在本表链接。没有足够依据就保留通用路径，不杜撰当地规则。

同一申请有多篇时建立“文书ID—题目—核心证据—已用故事—新信息”小表；允许重复重要事实，但避免同一故事同一结论整段重用。每校独立S账本；一篇不要求学校联系时，不自动加Why school。
