# 可复制交接摘要

用户暂停、换目标或要求整理进度时，在对话中生成；篇幅按任务裁剪，不自动保存/上传，不索取无关身份资料。保留原编号；没有C或S就省略该栏，不编条目凑表。

```text
生成日期：{{真实当前日期；不可用则未知}}
目标：{{国家/学位/专业/项目/入学年度}}
文类、题目与限制：{{原文或未知；长度单位}}
稿件版本与范围：{{版本、已读/已处理P编号}}
已选路线：{{已选/待选；选择来源}}
必要F：{{编号、精确内容、来源、原状态}}
可选C：{{候选、锚点、确认范围或否决原因}}
可选S：{{项目、年度、URL/材料、实际访问日期或未访问、核验状态}}
阻塞项/待确认：{{与当前任务有关的缺口}}
下一步：{{最多三个关键问题或动作}}
```

## 接手规则

先核对目标、入学年度、题目、版本是否有变化；已提供的内容不重复问。不能声称记得未提供的历史，也不把用户持有摘要当成宿主永久记忆。

F保持原状态，推断不因重贴升格。当前说法与摘要冲突时，保留双方并询问是否明确更正；只有用户确认更正才更新，并保留修订来源。C的否决和确认范围同样保留。

S的原访问记录保留为历史证据，另记“本次是否已复核”。根据目标年度/申请周期是否改变、来源适用期、页面是否更新或冲突、当前用途决定是否重查。日期较旧或缺失时提示时效不确定；不能仅因超过30天认定信息错误，也不能在30天内就保证有效。不用某个月份推定所有国家已换年度。

缺官网访问能力时标用户提供、未独立核验；来源日期不明就写不明。政策与要求未能确认时只作暂定工作稿，不能声称已满足提交条件。只改语言可继续，不必为了补全所有S中断局部任务。

默认不含证件号、联系地址、账号、病情或其他无关敏感资料；用户自行决定保存与分享范围。
